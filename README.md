# OLED 設計教室

線上網站：https://shuan14408-ops.github.io/oled-classroom/

在瀏覽器上逐格畫出圖案，並一鍵轉成可以在 Arduino 與 OLED 螢幕（SSD1306）上顯示的程式碼。

## 設計理念

- **先理解「像素」與「座標」**：從 16 × 16、32 × 32 的小畫布開始，學生親手點亮每一格，理解螢幕是由像素組成，座標從左上角 (0, 0) 開始。
- **從設計到實作一條龍**：畫好的圖案可以直接匯出 Arduino 程式碼（`.ino`），燒錄後就能在真正的 OLED 螢幕上看到成果，連接「數位設計」與「實體運算」。
- **降低技術門檻**：中文字會自動轉成點陣圖，不必另外安裝字型；畫面右側即時預覽 128 × 64 的 OLED 效果，學生可以邊畫邊確認。
- **兩種創作方式**：像素模式適合細部點畫；向量模式保留線條、矩形、橢圓與文字物件，可以選取後拖曳調整。
- **善用 AI 的學習方式**：可以產生帶有目前圖案資料的「AI 提示詞」，引導學生學習如何向 AI 清楚描述需求，請它協助延伸程式。
- **作品可以保存與分享**：下載 JSON 檔可下次繼續編輯，PNG 檔適合放進學習單或作品集。

## 開發過程

1. 從 OLED 教學的常見門檻出發：圖案資料（位元組陣列）難以手寫，也不容易想像畫出來的樣子。
2. 使用 AI 程式開發工具協助撰寫程式，再依實際操作的結果反覆調整畫布尺寸、工具列與匯出流程。
3. 實作 1-bit 黑白點陣轉換、中文字點陣化，以及 Adafruit GFX／SSD1306 程式碼產生。
4. 完成後發布為靜態網站，部署到 GitHub Pages。

## 技術

- HTML / CSS / JavaScript（無框架）、Canvas
- 匯出的程式使用 Adafruit GFX 與 Adafruit SSD1306 程式庫

## 分支說明

- `main`：原始碼（網站檔案在 `dist/`）
- `gh-pages`：部署到 GitHub Pages 的靜態檔案
