OLED 設計教室從一個像素開始，練習設計與程式。

第一次使用

  1. 選擇畫布

    初學先用 16 × 16 或 32 × 32。座標從左上角的 (0, 0) 開始。

  2. 畫出圖案

    像素模式直接畫；向量模式保留線條、矩形、橢圓與文字，可用選取工具拖曳物件。

  3. 保留作品

    下載 JSON 可以下次繼續編輯。PNG 適合放入學習單或展示。

  4. 顯示在 OLED

    匯出的 .ino 適用 I²C SSD1306 128 × 64 / 128 × 32 顯示器。Arduino IDE 需安裝 Adafruit GFX Library 與 Adafruit SSD1306。接線依開發板的 SDA / SCL 標示與螢幕規格。

向量圖形與中文字會轉為黑白點陣匯出，保留畫面外觀。切換模式不會清除作品。鍵盤：畫布取得焦點後，用方向鍵與空白鍵編輯像素。

匯出 Arduino 程式碼

圖案置中。若圖案超出螢幕高度，請先調整畫布尺寸。

使用 Adafruit GFX 與 Adafruit SSD1306 程式庫；中文字已轉為點陣，不需另外安裝字型。
